# Internal I2C and I2S bench validation — 2026-09-07

Result: both boards built and flashed successfully with ESP-IDF v5.5.1;
combined Si5351/I2S tests passed on the wired hardware after two startup fixes.

## Setup

| Function | Tab5 M5-Bus / ESP32-P4 | YD ESP32-S3 |
| --- | --- | --- |
| I2C SDA | pin 17 / GPIO31 | GPIO8 |
| I2C SCL | pin 18 / GPIO32 | GPIO9 |
| MCLK | pin 2 / GPIO16 | GPIO4 |
| BCLK | pin 8 / GPIO45 | GPIO5 |
| LRCK | pin 19 / GPIO3 | GPIO6 |
| ADC DOUT | pin 20 / GPIO4 | GPIO7 |
| Ground | GND | GND |

The user fitted 43/47 ohm I2S series resistors. Both boards are USB powered.
I2C runs at 100 kHz with the Tab5's onboard pull-ups and both MCUs' weak
pull-ups disabled. Mock port: `/dev/cu.usbmodem5A7A0113341`.
Tab5 port: `/dev/cu.usbmodem101`.

I2S uses 48 kHz stereo Philips format, 24 significant bits in 32-bit slots,
12.288 MHz nominal MCLK and 3.072 MHz nominal BCLK. The mock independently
qualified MCLK near 12.25 MHz using its short software-timed counter gate;
this is a gross-frequency check, not an oscillator accuracy measurement.

## Fixes found on hardware

1. **Host-only reset retained old TX samples.** The first run passed, but the
   next run synchronized to old pattern sequence `0x1FA4` and failed 92 frames
   later when buffered silence arrived. Increasing the initial mock-test drain
   from 1,440 to 4,800 frames covers both DMA rings, the in-flight write, and
   MCLK requalification. Every subsequent checked frame must still match;
   continuity errors are never skipped after synchronization.
2. **Simultaneous startup delayed mock I2S initialization.** Si5351 answered
   at about 289 ms, while its transaction logger delayed PCM1808 setup until
   about 919 ms; the host had already stopped its unsuccessful I2S test.
   The mock now initializes PCM1808 before enabling I2C. The host also allows
   up to two seconds for address `0x60` to appear after startup.

## Verification

| Configuration | Runs | Frames checked | Result |
| --- | --- | --- | --- |
| Long capture: 480,000 frames / 10 seconds | USB-open combined startup + 3 controlled runs | 1,920,000 | PASS |
| Final quick capture: 4,800 frames / 0.1 seconds | USB-open combined startup + 3 controlled runs | 19,200 | PASS |

The controlled runs reset the mock once, then reset only the Tab5 between
tests. Every capture first discarded 4,800 startup frames. The longer runs
crossed the 16-bit sequence wrap repeatedly without a mismatch.

The host verified the Si5351 register programming, readback, PLL-reset
behavior, and RX → TX-ready → RX clock transitions. The mock independently
validated PLLA/B at 792.288 MHz, CLK0 at 7.074 MHz, and CLK1 at 28.296 MHz.
All runs ended in RX (CLK1 enabled, CLK0 disabled), with I2S clocks released.
The mock detected MCLK loss after every controlled run. There were no firmware
errors or dropped transaction logs in the final or stress captures.

The generic ESP-IDF pull-up warning is emitted whenever internal pull-ups are
disabled; it does not measure external pull-ups. One counter gate overlapped
normal clock shutdown during the stress test and reported a partial-frequency
sample after host PASS; the monitor then revoked the pattern as intended.

## Final installed configuration and evidence

Both boards retain the tested firmware. Tab5 uses GPIO31/GPIO32 and the quick
4,800-frame test; the temporary 480,000-frame setting was restored and the
final configuration rebuilt, reflashed, and retested. The local mock-only TX
clock exercise remains enabled as in the earlier bench setup; tracked defaults
keep that option disabled for real RF hardware.
